# AnimalTetris 🐾

Een Tetris-spel waarin alle blokken dieren zijn: 🐍 slang, 🐷 varken, 🐱 kat, 🐸 kikker, 🦊 vos, 🐧 pinguïn en 🐰 konijn.

## Spelen

Open `index.html` in je browser. Meer is er niet nodig — alles zit in één bestand.

## Besturing

| Toets | Actie |
| --- | --- |
| ← / → | Blok bewegen |
| ↑ of X | Draaien |
| Z | Tegenklok in draaien |
| ↓ | Sneller zakken |
| Spatie | Harde val |
| P | Pauze |

Op mobiel verschijnen er automatisch aanraakknoppen onder het speelveld. Je kunt ook
met je vinger over het speelveld **vegen**:

| Gebaar | Actie |
| --- | --- |
| Tikken | Draaien |
| Links/rechts vegen | Blok bewegen |
| Omlaag vegen | Harde val |
